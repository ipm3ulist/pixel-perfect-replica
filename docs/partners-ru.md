Условия меняются часто: перед подключением сверяйте их в личном кабинете программы.
**Ни одна ссылка на сайт пока не добавлена.** Оффер попадает на сайт только после регистрации, одобрения площадки и получения рекламного идентификатора (erid) для маркировки.

## Порядок подключения
1. Опубликовать сайт на постоянном домене: модерация обычно требует живую площадку с трафиком.
2. Подать заявку в Лемана ПРО (напрямую) и в Яндекс Маркет (Дистрибуция). Остальные магазины — через одну CPA-сеть.
3. После одобрения внести оффер в `src/monetization/config.ts` (`PARTNER_OFFERS`), указав erid, рекламодателя и дату проверки. Без erid оффер на сайте не покажется.
4. Покупки учитывать только по отчётам программы. Клик по ссылке — не продажа.

Пароли от партнёрских кабинетов в чат не передавать.
