Как считаем

  1. Площадь плитки = ширина × длина
  2. Плиток = площадь × (1 + запас) ÷ площадь плитки, вверх
  3. Упаковок = плиток ÷ штук в упаковке, вверх

Расчёт не учитывает ширину шва и конкретную раскладку. Для сложных помещений точнее посчитать по раскладке. Все расчёты на сайте предварительные и не заменяют проект, смету или консультацию профильного специалиста. Значения в полях по умолчанию — пример заполнения, а не норма.
