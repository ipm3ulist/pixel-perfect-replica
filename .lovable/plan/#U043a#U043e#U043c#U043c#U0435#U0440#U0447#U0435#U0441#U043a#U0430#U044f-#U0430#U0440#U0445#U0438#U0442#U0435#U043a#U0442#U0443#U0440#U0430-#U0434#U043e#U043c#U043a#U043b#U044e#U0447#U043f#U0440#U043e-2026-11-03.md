# Коммерческая архитектура ДомКлючПро

Принцип: портал остаётся редакционным справочником. Любой коммерческий блок — дополнение к полезному содержанию, всегда помечен, по умолчанию выключен и не показывается без реальных подтверждённых данных.

## 1. Централизованные данные (без правки компонентов)
`src/monetization/data/`:
- `stores.ts` — магазины/партнёрские сети: название, сайт, программа, статус подключения, `erid`, рекламодатель (ИНН/наименование для маркировки).
- `products.ts` — товары: название, изображение, магазин (ID), описание, ссылка, категория каталога, цена только с полями `source` + `checkedAt` (без них цена не выводится).
- `catalog.ts` — 9 разделов каталога (обои, краски/грунтовки, полы, плитка, утеплители, кровля, блоки/кирпич, инструменты, сухие смеси) с привязкой к существующим материалам, статьям и калькуляторам.
- `comparisons.ts` — таблицы сравнения: только ссылки на свойства из существующих материалов; пустые значения показываются как «нет данных», цены — «уточняйте у продавца».
- Демо-записи: флаг `demo: true`, плашка «Демонстрационный пример — не предложение», не попадают в sitemap и публичную выдачу при `enabled`.
- `validateMonetization()` (тесты): ссылки на несуществующие магазины, офферы без `erid`, цены без источника, демо в продакшн-режиме — ошибка.

## 2. Компоненты (`src/monetization/components/`)
- `AdLabel` — единая маркировка «Реклама · рекламодатель · erid».
- `ProductCard` / `ProductList` — карточка и компактный список товаров.
- `WhatYouNeed` — блок «Что понадобится» (инструменты/материалы из статьи, без ссылок, если офферов нет).
- `MaterialsForWork` — «Материалы для работы»: категории каталога + реальные офферы, если есть.
- `CalculatorNextStep` — после расчёта обоев, плитки, краски, ламината: «Подобрать материалы» с передачей результата (кол-во рулонов/м²/литров) в каталог.
- `ComparisonTable` — адаптивная таблица сравнения (характеристики, применение, ограничения, ориентир стоимости).
- `LeadForm` + `ConsentCheckbox` — форма заявки.

## 3. Страницы
- `/katalog` и `/katalog/$section` — 9 разделов: описание, как выбирать, связанные статьи/калькуляторы, товары (пока пусто или демо с маркировкой).
- `/sravnenie/$slug` — страницы сравнения.
- `/zayavka` — заявка на ремонт/строительство: тип объекта, вид работ, город, сроки, контакт. Явное согласие; текст «данные никому не передаются, исполнителей пока нет». Подрядчики не создаются.
- `/reklama` — правила размещения и маркировки (для прозрачности).

## 4. Заявки — хранение
Нужен бэкенд (Lovable Cloud): таблица заявок, запись только с сервера, читать могут только вы. Без включения Cloud форма будет показана как «приём заявок скоро» — без имитации отправки.

## 5. Аналитика
Встроенные события проекта (без сторонних счётчиков, без персональных данных):
`project.material_viewed`, `project.calculator_calculated`, `project.store_clicked` (store_id, product_id, placement), `project.lead_submitted` (тип объекта, вид работ — без контактов).

## 6. Партнёрские программы РФ — исследование
Отчёт в `docs/partners-ru.md`: Яндекс Маркет (партнёрская программа), Ozon, Wildberries, Admitad, Advcake, Leroy Merlin/Лемана ПРО, Петрович, ВсеИнструменты, OBI и т.п. — что доступно, условия, требования к маркировке (ОРД, erid, закон 347-ФЗ). Только факты из открытых источников со ссылками; ни одной ссылки в сайт без подтверждённого подключения.

## Технически
- Флаги в `config.ts`: `affiliateEnabled`, `adsEnabled`, `leadsEnabled`, `showDemo`.
- Блоки встраиваются в статьи через поля `needs`/`catalogSections` в существующей модели контента.
- Тесты: валидатор, правило «нет erid — не показывается», «нет источника — нет цены», демо скрыто в продакшене.
