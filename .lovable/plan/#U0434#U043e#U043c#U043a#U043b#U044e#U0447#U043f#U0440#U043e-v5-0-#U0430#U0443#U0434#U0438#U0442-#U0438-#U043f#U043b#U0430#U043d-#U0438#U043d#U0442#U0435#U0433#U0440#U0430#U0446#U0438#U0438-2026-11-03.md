## 1. Что оставляем из текущего ДомКлючПро (всё)
Маршруты (27), контентная модель, 32 статьи, 8 материалов, 35 терминов, калькуляторы (обои, краска, плитка, ламинат, блоки, бетон, утеплитель), поиск, SEO и sitemap, мегаменю, дизайн и бренд, модуль монетизации (выключен), тесты.

**Ошибка сборки из ТЗ:** в этом ZIP подвал ссылается на /katalog, /zayavka, /reklama, и все три страницы есть. Скорее всего, ошибка уже исправлена. Это подтвердит сборка после переноса.

## 2. Что можно перенести из найденного «Pixel-Perfect Replica»
| Что | Решение |
|---|---|
| Три примера домов (projects.ts + 3 фото) | Перенести как демо-сценарии для /doma/proekty, без цен и старого бренда |
| Параметры калькулятора (пакет, фундамент, кровля, утепление, отделка, этажность) | Взять только набор полей для конфигуратора |
| Проверка и маска телефона | Можно переиспользовать в форме заявки (режим «скоро») |
| Поля заявок заказчика и бригады | Только как идея полей |

## 3. Что переносить нельзя
- Денежные коэффициенты DEMO_RATES (38–72 тыс./м² и др.): это демо-цены без источника.
- Отправка заявок на API_SUBMIT_URL / trycloudflare и сбор данных браузера.
- Каталог бригад, обещание «подберём бригаду», старые контакты и бренд, региональные коэффициенты.

## 5. Риски и зависимости
- **Главное:** без настоящего донорского ZIP нельзя проверить конфигуратор, смету и базу позиций из ТЗ. Без него я соберу их по полям из ТЗ с собственными проверенными геометрическими формулами (площадь пола, периметр, стены, кровля по уклону) и тестами.
- Партнёрские ссылки не добавляются, пока нет подтверждённого участия в программах.
- Lovable Cloud не включается: формы работают в режиме «Приём заявок скоро».
- Статический экспорт на GitHub Pages: отдельная задача, она уже была открыта.
